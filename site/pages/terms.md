## 3. 数据使用规范

- **允许的用途**：个人日常阅读、学术与行业研究、企业或团队内部情报分享、通过个人 AI Agent / RSS 阅读器接入辅助阅读，以及注明出处与原文链接的非商业性摘引。

## 4. 开放接口与请求频率

本站提供的 RSS（`/feed.xml`）、公开 REST API（`/api/v1/*`）与 MCP（`/api/mcp`）均为免费匿名只读接口。调用方应遵守 HTTP 响应头中的 `Cache-Control` 缓存周期进行合理轮询；若触发 `429 Too Many Requests` 限流保护，请严格遵循 `Retry-After` 响应头等待恢复，严禁使用高并发脚本恶意抓取或攻击本站服务。
